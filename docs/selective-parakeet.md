# GigaAM + выборочный Parakeet

Режим `gigaam_parakeet` сохраняет GigaAM v3 e2e RNNT int8 основным распознавателем. Parakeet TDT 0.6B v3 Q8_0 проверяет только автоматически выбранные фрагменты и может исправить технический термин внутри готовой реплики. Он не переписывает весь разговор. Режим доступен в настройках сайта и на странице проверки качества.

## Отбор и защита текста

1. GigaAM обрабатывает оба канала с прежним Silero VAD и разбиением на реплики. Дополнительно сохраняется уверенность токенов, без изменения декодирования. Вероятности моделей — эвристика отбора, а не калиброванная вероятность правильности слова.
2. Проверка Parakeet включается, только если в разговоре есть фонетическое сходство с термином из словаря `TERMS` в `integrations/transcription/selective.py`. Затем отбираются окна с похожими терминами и неуверенными словами: вероятность слова ниже 0.65 либо минимум два слова ниже 0.80. Слова словаря имеют приоритет.
3. Окно принадлежит одному каналу, занимает до 20 с исходной записи (одиночный VAD-интервал может иметь дополнительные поля), содержит минимум 6 с речи с полями VAD. Паузы между VAD-интервалами вырезаются, поля 300 мс сохраняются. Бюджет на весь звонок — 15% речи обоих каналов, минимум 12 с, максимум 60 с; не более восьми окон. Минимум бюджета не означает обязательного запуска: слишком короткие окна пропускаются.
4. Донор должен предложить известный термин латиницей вместо одного-двух слов внутри одной реплики. Требуются фонетическое сходство не ниже 0.4, вероятность каждого слова донора не ниже 0.9, совпадающее слово с каждой стороны и не менее трёх совпадающих соседних слов суммарно. Замены около склейки аудио отклоняются.
5. Числа, служебные слова, границы реплик, говорящие и каналы защищены. Изменяется только участок `text`. Все временные метки GigaAM сохраняются точно; временные метки Parakeet служат только для отбраковки сомнительных склеек. Русские слова не заменяются другими русскими словами.

Это намеренно ограниченный корректор терминов. Неизвестный словарю термин, разговор без узнаваемой подсказки, термин в очень короткой реплике или без совпадающего контекста может остаться ошибочным. В словаре нет привязки к именам файлов, номерам телефонов или временным меткам контрольных записей. Добавление новых терминов и ослабление правил требуют повторной проверки.

## Память и отказоустойчивость

Первый проход использует прежнюю конфигурацию GigaAM: на проверенном Raspberry Pi два канала и два ONNX-потока. После него один отдельный процесс Parakeet последовательно проверяет выбранные окна четырьмя потоками. Если окон нет, процесс и модель не запускаются. Завершение процесса возвращает память ОС; веса Parakeet не остаются в процессе бота.

Максимальное ожидание второго процесса — 180 с. Отсутствующая модель, повреждённый ответ, таймаут или падение native runtime сохраняют результат GigaAM. В JSON звонка поле `correction` содержит статус, количество и длительность выбранных окон, время проверки и журнал принятых замен с исходным текстом и границами реплики. Сбой отмечается в журнале бота; он не превращает звонок в пустую расшифровку. Обычный режим `gigaam` не запускает корректор.

## Установка

Веса и runtime скачиваются заранее, вне обработки звонков. Установщик проверяет фиксированные SHA-256 и ревизии; аудио никуда не отправляется. Поддерживаются Linux aarch64 и x86_64. Для других платформ сначала нужна отдельная проверка runtime.

```sh
cd /opt/sms
venv/bin/pip install --no-deps --require-hashes -r requirements-parakeet.txt
sudo install -d -o asterisk -g asterisk /opt/sms/var/models/parakeet
sudo -u asterisk venv/bin/python tools/install_parakeet.py
```

Для установки из проверенных локальных файлов передайте `--archive` и `--model-file`; для отдельного каталога — `--root`. Уже существующий runtime не перезаписывается. Python binding `transcribe_cpp` закреплён на версии 0.2.3; остальные зависимости бота сохраняются.

| Переменная | По умолчанию |
| --- | --- |
| `CALL_TRANSCRIBE_PARAKEET_MODEL_PATH` | `/opt/sms/var/models/parakeet/parakeet-tdt-0.6b-v3-Q8_0.gguf` |
| `CALL_TRANSCRIBE_PARAKEET_LIBRARY_PATH` | `/opt/sms/var/models/parakeet/runtime/libtranscribe.so` |
| `CALL_TRANSCRIBE_PARAKEET_THREADS` | `4` |

После установки обновите бот, перезапустите его вне активного звонка и обновите PHP-файлы из [инструкции сайта](../web/README.md). Выберите «GigaAM + Parakeet» в настройках. До первого чтения настроек UI движок определяется `CALL_TRANSCRIBE_BACKEND`; при необходимости задайте там `gigaam_parakeet`. Для возврата достаточно выбрать GigaAM. Выбор не переписывает ранее сохранённые звонки.

Проверка без отправки уведомлений:

```sh
venv/bin/python -m integrations.transcription recording.wav \
  --backend gigaam_parakeet --gigaam-model-path /opt/sms/var/models/gigaam-v3-e2e-rnnt-int8 \
  --channel-workers 2 --cpu-threads 2 -o /tmp/selective.json
```

На странице «Проверить качество» используются те же правила, но браузерное аудио декодируется в моно. Результат сохраняет построчные метки GigaAM. Проверка не меняет выбранный движок звонков и не отправляет уведомления.

## Проверка полного архива на Raspberry Pi 5, 17.10.2026

133 оригинальные стереозаписи, 8112.54 с аудио. Два исправления технических терминов в одной записи подтверждены владельцем по аудио; после уточнения словаря и защитных правил они применены автоматически. Других изменений текста нет: все 132 остальные записи совпали с GigaAM. Во всех 133 сохранены числа, говорящие, каналы и временные метки каждой реплики; тихие каналы не получили текста, повторные IVR-реплики сохранены.

Подтверждённый фрагмент использован при разработке правил. Это один калибровочный пример и 132 регрессионных записи, **не независимая оценка WER**. Результат подтверждает локальную пользу корректора, но не доказывает общий процент улучшения распознавания. Первоначальный более широкий отбор проверял 57 окон в 34 звонках без принятых замен; итоговый вариант требует узнаваемой подсказки термина и проверяет 10 окон в двух звонках. Названия файлов и время подтверждённых фраз не участвуют в отборе.

| Показатель | GigaAM | GigaAM + выборочный Parakeet |
| --- | --- | --- |
| Весь архив | 583.00 с | 630.31 с (+8.11%) |
| CPU-секунды | 1797.85 | 1932.07 |
| Пиковый RSS | 1421 МиБ | 2143 МиБ, родитель + дочерний процесс |
| Дополнительное распознавание | — | 115.188 с аудио, 1.66% речи |
| Запись 22 мин 54.5 с | 111.79 с | 129.40 с, без замен |
| Контроль 9.04 с с тихим каналом | 0.48 с | 0.58 с, без замен |

Один проход каждого варианта на Pi 5 8 ГБ, четыре Cortex-A76, Debian 12 / Python 3.11.2. Время связки измерено целиком: декодирование, VAD, GigaAM, отбор, запуск и загрузка Parakeet, исправления, завершение процесса. Первоначальная загрузка/прогрев GigaAM исключены; загрузка Parakeet в двух дочерних процессах включена. Очередь и доставка не измерялись. Порядок связки начинался с контрольных записей; это однократное эксплуатационное сравнение, без доверительного интервала.

Память связки измерялась каждые 0.25 с как сумма RSS родителя и ребёнка: общие страницы могут учитываться дважды. У GigaAM RSS измерялся каждые 0.5 с. После каждого второго прохода ребёнок завершился; только GigaAM остался резидентным. Минимально доступная память системы — 3892 МиБ, максимальная температура — 68.3 °C; `vcgencmd get_throttled` после теста — `0x0`. Активных звонков при контрольных проверках не было. Веса и runtime добавляют около 765 МиБ на диске, Python binding — менее 1 МиБ.

Полный Python-набор: 91 тест на Raspberry. Дополнительно прошли проверки PHP-хранилища настроек/очереди и 20 браузерных JS-тестов. Проверены таймаут и падение дочернего процесса, тишина, границы бюджета, защита чисел и реплик, отклонение иностранных галлюцинаций и сомнительных склеек. Исходные аудио, имена файлов с номерами, полные расшифровки и приватный интерактивный отчёт в Git не включены.
