# Настройки распознавания в веб-интерфейсе

Этот каталог — обновление существующего PHP-хостинга Calls / SMS, а не отдельная установка сайта. Он добавляет «Настройки → Распознавание речи» с выбором **GigaAM** или **faster-whisper**.

Загрузите рядом с существующим `common.php` четыре файла:

* `index.php`
* `sw.js`
* `transcription_settings.php`
* `transcription_settings_store.php`

Перед заменой сохраните копии `index.php` и `sw.js`. Существующие `common.php`, `vendor/`, `icons/` и `sip-private-data/` остаются на хостинге. `common.php` содержит конфигурацию доступа и намеренно не включён в репозиторий.

Настройка хранится в `DATA_STORAGE_DIR/transcription-settings.json`, запись выполняется атомарно. PHP-пользователь должен иметь право записи в этот каталог. UI требует существующую сессию администратора и CSRF-токен; допустимы только `gigaam` и `whisper`. Бот читает отдельный GET endpoint через тот же заголовок `Authentication`, который используется для сохранения звонков. Запись через этот endpoint запрещена. API и динамические страницы не кэшируются service worker.

Одновременно обновите бот и его зависимости по инструкции в [../docs/transcription.md](../docs/transcription.md). Один лишь новый UI не меняет поведение старой версии бота. Новый бот по умолчанию находит endpoint рядом с `EVENT_STORE_CALL_URL`; при другом размещении задайте `CALL_TRANSCRIBE_SETTINGS_URL` явно.

Выбор применяется перед началом следующей транскрибации. Уже обрабатываемая запись завершается прежним движком; старые расшифровки не переписываются. Во время недоступности endpoint процесс использует последний успешно прочитанный выбор, а до первого успешного чтения — `CALL_TRANSCRIBE_BACKEND` из окружения.
